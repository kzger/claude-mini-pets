Claude Mini Pets

兩個獨立版本，適用於支援寵物安裝連結的 Codex／ChatGPT 桌面 App。

若同帳號已列出這兩隻寵物，直接在 App 寵物清單選用即可，無須重複匯入。

Claude 娘

一般版，表情變化較明顯。

安裝一般版

Claude 娘・流暢版

流暢版，較小幅的連續動作與固定腳底。

安裝流暢版
使用方式
  1. 先安裝並開啟桌面 App，保持網路連線。
  2. 按上方按鈕，在瀏覽器的「開啟 Codex／ChatGPT」提示中選擇已安裝的 App。
  3. 在 App 內完成寵物安裝，再到設定 → Pets／Mini & Pets 選用。

按鈕使用官方 codex://pets/install 流程；圖片來自本專案 GitHub 的固定版本。

若按鈕無反應，改從 GitHub Releases 下載 ZIP，依 README 複製兩個本機寵物資料夾。

原生 App 的 hover 仍會播放三輪；此頁沒有修改播放次數或原生解析度。
